AI CAREER COUNSELOR CHATBOT PROGRESS LOG
=========================================

Date: 08/06/2026
----------------

Detailed description of what was implemented:

1. Environment Configuration & Validation
   - Added `GROQ_API_KEY` to `Server/.env` file.
   - Updated `Server/config/env.js` to crash early at startup if `GROQ_API_KEY` is missing and export `groqApiKey` dynamically.

2. Secure Groq API Service
   - Created `Server/services/groq.service.js` which houses standard API wrappers using `axios` to query Groq's completions endpoint (`https://api.groq.com/openai/v1/chat/completions`).
   - Configured `llama-3.1-8b-instant` as the default model, supplying sub-second, highly smart responses with a 20s request timeout.

3. Context-Aware Student System Prompting
   - Built `Server/controllers/chatbot.controller.js` to pull full student profiles from MongoDB:
     - User onboarding properties: name, age, city/state, stream, education.
     - User competency matrices: current skills list and selected interests.
     - User AI recommendations: predicted domain and actual 3 recommended career cards (including salary figures, growth metrics, missing skills, and detailed roadmaps) retrieved from the compound MongoDB `MlCache` using the student's `lastMlSkillsHash`.
   - Aggregates this profile into a system prompt that enforces professional counseling rules, Indian tech job contexts, and direct alignment with their recommended roadmaps.

4. Secured Chatbot Routing Group
   - Added `Server/routes/chatbot.routes.js` with `POST /` route, protected by `authMiddleware` to isolate chats to logged-in students.
   - Mounted the chatbot route group dynamically under `/api/chatbot` in `Server/routes/index.js`.

5. Automated Verification Script
   - Created `Server/scratch/test_chatbot.js` which connects to local MongoDB, extracts/creates a mock student record with predicted careers, compiles the target system instructions, and executes a real prompt against Groq API.
   - Verified that Groq correctly addresses the user by name, references their current python skills, and gives detailed, contextual instructions about their recommended roadmap.

Date: 12/06/2026
----------------

Detailed description of what was implemented:

1. Interactive Client Chat UI (Chatbot.jsx & Chatbot.css)
   - Created a responsive, full-page layout including a contextual student profile sidebar (displaying current stream, education, skills, interests, and target careers matches) and a spacious chat workspace panel.
   - Wired up conversation history state to the POST /api/chatbot Express endpoint.
   - Built dynamic query suggestion chips (e.g., transition advice, routines, skill gap checks) that automatically submit requests on click.

2. Advanced Markdown Format Parsing
   - Built a robust parser (`renderFormattedMessage`) that reads text output and structures standard lists, bold elements (`**`), interactive checklist checkboxes (`- [ ]`), styled callout boxes (`> `), and client-link buttons (`[Label](/student/path)`) into native React nodes.

3. Integration Debugging & Refinement
   - Resolved a payload mismatch where the client-side role key clashed with the controller's mapping function, triggering Groq 400 content missing errors.
   - Eliminated page-bouncing scroll bugs by swapping the global scrollIntoView() function with container-specific scrollTop settings.
   - Replaced placeholder "Progress" tabs across all student navigation headers (Dashboard, CareerRecommendation, Courses, SkillgapAnalysis, CollegeRecommendation, Profile) to correctly direct users to "AI Assistant" (/student/chatbot).

4. Token Volume & Rate Limit Optimizations
   - Prevented 429 rate limits by condesing roadmap step strings inside system prompts (removing verbose descriptions) and slicing history to the last 6 messages.
   - Implemented a 1.5s automatic retry backoff inside the Axios client wrapper upon catching 429 errors.
   - Corrected template literal nested backticks syntax errors in controllers to prevent server startup crashes.
